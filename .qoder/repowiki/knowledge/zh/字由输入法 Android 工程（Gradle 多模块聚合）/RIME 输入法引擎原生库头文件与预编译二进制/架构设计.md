本模块是纯静态资源目录，不包含任何源码或构建脚本，仅由两部分组成：
- `include/`：RIME 引擎对外暴露的 C API 头文件集合，核心为 `rime_api.h`，定义了 `RimeApi` 结构体及所有函数指针（会话管理、输入处理、候选词、配置读写、部署等），并通过 `RIME_FLAVORED` 宏实现版本兼容；同时包含 `utf8/` 子目录（Nemanja Trifunovic 的 utf8-cpp 库）、`darts.h`（双数组 Trie）以及 `rime_levers_api.h`、`rime_api_deprecated.h`、`rime_api_stdbool.h` 等辅助接口。
- `arm64-v8a/`：针对 Android arm64-v8a 架构预编译的二进制库（.so），由上层 NDK 构建流程链接。
依赖方向单向：Android 应用层通过 JNI 加载该目录下对应 ABI 的 .so，并包含 `include/` 中的头文件进行编译，模块本身不参与构建，仅作为第三方库分发。
