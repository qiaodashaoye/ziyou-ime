首次构建需先获取 librime 源码（方式 A：`git submodule add https://github.com/rime/librime.git librime-prebuilt/librime && git submodule update --init --recursive`；方式 B：由 build.sh 自动 clone）。NDK 路径可通过 `ANDROID_NDK_HOME`、`local.properties` 中的 `sdk.dir` 或 `ANDROID_SDK_ROOT` 自动探测。常用命令：`make librime`（等价于 `./build.sh` 编译全部 ABI）、`./build.sh arm64-v8a`（单 ABI）、`make lua`（启用 WITH_LUA=ON）。
