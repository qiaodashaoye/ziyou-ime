- 所有对外 API 统一声明为 `suspend` 函数，并在实现中通过 `dispatcher.dispatch { ... }` 派发到 Rime 专属单线程执行。
- JNI 方法集中在 `object` 中声明为 `@JvmStatic external`，并在 `init` 块中尝试 `System.loadLibrary("rime_jni")` 记录加载状态。
- C++/JNI 数据结构以 Kotlin `data class` 表示，并为 JNI 侧构造提供无参构造函数（如 `CommitProto()`）。
- 跨进程回调通过 `sealed class` 枚举消息类型，并由 `RimeMessageHandler` 的 `MutableSharedFlow` 经 `asSharedFlow()` 暴露只读流。
- 生命周期操作（initialize/destroy/redeploy）通过 `Mutex.withLock` 串行化，避免并发导致的重复初始化与线程泄漏。
