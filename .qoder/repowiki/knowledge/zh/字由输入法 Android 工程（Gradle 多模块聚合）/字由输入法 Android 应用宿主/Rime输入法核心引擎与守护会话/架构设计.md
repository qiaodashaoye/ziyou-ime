模块按职责分为两个包：
- `core`：定义 `RimeApi` 接口及 `SimpleRimeImpl` 实现，所有 suspend 方法通过 `RimeDispatcher`（基于 `Executors.newSingleThreadExecutor` + `asCoroutineDispatcher()`）串行执行，确保对非线程安全的 `RimeNative` JNI 调用的互斥访问；`RimeNative` 集中声明 `@JvmStatic external` 方法与 `rime_jni` 库绑定，`RimeConfig` 提供独立的配置文件读写 JNI 接口；`ProtoTypes.kt` 中的 data class（CommitProto/ContextProto/StatusProto/CandidateProto/SchemaItem 等）与 C++ 层 Proto 一一对应，由 native 代码构造；`RimeMessage.kt` 使用 sealed class 表达 Schema/Option/Deploy/Unknown 四类通知，并通过 `RimeMessageHandler` 的 `MutableSharedFlow` 广播给 UI。
- `daemon`：`RimeSession` 作为单例门面，实现 `RimeEngine`（外部接口），用 `Mutex` 串行化 initialize/destroy/redeploy，内部组合 `RimeDispatcher`、`SimpleRimeImpl` 和协程作用域，负责 AssetDeployer 资源部署、DictManager 扩展词库注入、目录创建以及带超时的引擎启动。
依赖方向单向向下：daemon → core → JNI；UI 仅依赖 `RimeApi` 与 `RimeMessage` 流。
