本模块以 CMake 构建共享库 `rime_jni`，核心由四个职责分明的文件组成：
- `rime_jni.cc`：JNI 入口与 Rime 引擎单例封装。`JNI_OnLoad` 初始化全局引用并声明可选模块依赖；内部 `Rime` 类通过静态单例管理 `rime_get_api()`、会话生命周期（`SessionHolder`）以及所有引擎操作（按键处理、提交、上下文/状态获取、方案与候选词操作）。
- `config.cc`：独立的配置读写 JNI 接口，暴露 `open/close/get/set` 系列方法，通过 `jlong` 句柄在 C++ 与 Java 间传递 `RimeConfig*`。
- `jni-utils.h`：JNI 工具集，包含 `CString`/`JString`/`JRef` 等 RAII 包装器、`JEnv` 线程环境附加、以及 `GlobalRefSingleton` 缓存 Java 类与方法 ID（如 `com/ziyou/ime/core/RimeNative` 及其 Proto 类构造器）。
- `objconv.h` + `helper-types.h`：C++ 数据结构（`CommitProto`、`ContextProto`、`StatusProto`、`CandidateProto`、`SchemaItem`）到 Java 对象的转换函数，配合 `GlobalRefSingleton` 调用对应 Java 构造函数。
- `session.h`：RAII 的 `SessionHolder`，自动创建/销毁 `RimeSessionId`。
依赖方向单向：JNI 层 → helper-types/objconv → jni-utils → librime API，不反向依赖 Java 实现细节。可选模块（Lua/Octagram/Predict/OpenCC）通过 CMake `option` 开关和 `#ifdef WITH_*` 条件编译控制。
