根目录作为 Gradle 多模块项目的组合根（settings.gradle.kts 声明 :app 与 :core-logic），顶层 build.gradle.kts 仅集中插件版本，各子模块独立维护自身依赖。
- 依赖方向严格单向：`:app → :core-logic`（编译器强制），`:app` 内部再向下分 UI → IME → Core → JNI → Engine 五层，JNI 层链接 `native_libs` 提供的 rime_api 头文件与 arm64-v8a .so，并通过 CMake 调用 `librime_prebuilt` 产出的 librime.a。
- 原生构建链路：`librime_prebuilt` 通过 superbuild 从源码交叉编译 librime 及其依赖，合并为静态库；`native_libs` 提供公共头与预编译二进制；`app` 的 CMakeLists.txt 按 option() 开关可选模块（Lua/Octagram/Predict/OpenCC），实现最小二进制体积。
- 运行时通过 `di/AppContainer` 组合根注入 `RimeEngine` 接口，所有 RIME API 经 `RimeDispatcher` 单线程调度，保证 librime 线程安全；消息通过 SharedFlow 在 IME 服务与设置页之间广播。
- 测试策略：纯逻辑下沉到 `:core-logic` 后可独立 JVM 单测，`:app` 侧通过 `AppContainer.overrideRimeEngine()` 注入替身完成集成测试。
