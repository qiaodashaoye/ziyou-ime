- 所有对外 C API 使用 `extern "C"` 包裹并通过 `RIME_API` 宏导出，Windows 下区分 DLL 导入/导出，非 Windows 平台无特殊修饰。
- 结构体采用自描述版本控制模式：每个结构体首字段为 `int data_size`，初始化必须通过 `RIME_STRUCT_INIT(Type, var)` 宏设置，成员存在性通过 `RIME_STRUCT_HAS_MEMBER` 检测以实现向后兼容。
- 可选或可扩展示例结构体使用占位符字段（如 `char placeholder;`）配合 `RIME_FLAVORED` 宏包装，避免破坏 ABI。
- 模块注册统一通过 `RIME_REGISTER_MODULE(name)` 宏在库加载时自动完成，要求实现 `rime_<name>_initialize()` 和 `rime_<name>_finalize()` 两个函数。
