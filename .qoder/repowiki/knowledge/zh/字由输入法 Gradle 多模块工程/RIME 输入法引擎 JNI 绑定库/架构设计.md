该模块是纯静态依赖包，不包含源码，仅包含两类内容：
- `include/` 目录存放 C/C++ 公共头文件，核心是 `rime_api.h`（定义 RimeApi 结构体、RimeTraits/RimeSessionId/RimeContext/RimeStatus 等数据结构及全部 C API 函数指针）和 `rime_levers_api.h`（扩展的设置、切换器、用户词典操作），以及 `utf8/` 子目录下的 utf8-cpp 库头文件和 `darts.h`。
- `arm64-v8a/` 目录用于放置对应 ABI 的预编译 `.so` 或 `.a` 库文件（当前为空，由构建流程填充）。
- 通过 `RIME_FLAVORED` 宏实现版本化结构体扩展，配合 `RIME_STRUCT_INIT` / `RIME_STRUCT_HAS_MEMBER` / `RIME_API_AVAILABLE` 实现向前兼容；模块系统通过 `RIME_REGISTER_MODULE` 宏自动注册插件。
- 依赖方向单向：Android Java/JNI 层 → C API → 底层 librime 动态库，本模块仅暴露 C 边界。
