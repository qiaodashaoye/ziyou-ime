本模块为纯文档目录，按功能维度组织 Markdown 方案文档：
- `技能插件系统可行性方案.md` + `技能插件开发指南.md` 构成一对「架构设计 + 开发者手册」，定义 `.skill` zip 包规范、manifest.json schema、IMESkill Bridge API v4 能力矩阵（sendText/fetch/storage/clipboard/image/input/ui）以及 WebView 沙箱安全机制；
- `游戏悬浮输入法可行性方案.md` 基于 IME 窗口 `onComputeInsets` 触摸裁剪实现悬浮面板，复用现有 InputLogicController/RimeEngine；
- `符号键盘调研与设计方案.md` 采用左侧竖排分类导航 + 右侧符号网格的中文输入法标准范式，数据源复用 Rime symbols.yaml；
- `等级体系可行性方案.md` 以 commitText 上屏字符数为计分口径，通过 LevelStats/LevelRepository/LevelEngine 分层落地；
- `联想功能重构方案.md` 记录从应用层管线到纯引擎级 librime-predict 路线的最终决策。
文档间存在明确的依赖方向：开发指南引用可行性方案，各方案均声明对现有架构（ZiYouInputMethodService、InputLogicController、BaseKeyboardView）的最小侵入改造点。
