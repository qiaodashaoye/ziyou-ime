模块按职责分为三个子包：
- `ui/`：以 Activity 为入口的 UI 层。SettingsActivity 采用纯代码 View + LinearLayout 构建卡片式设置页，通过 DI 容器 `AppContainer.rimeEngine` 访问 Rime 引擎；DictManagerActivity、LevelActivity、SkillDevGuideActivity 使用 Jetpack Compose（经 `setContentViewWithTitleBar` 复用标题栏），并通过 `viewModels()` 注入 ViewModel（如 DictManagerViewModel）。LevelActivity 直接读取 `LevelRepository` 状态。
- `config/`：配置管理层，全部为 `object` 单例，分别负责不同维度：`AssetDeployer` 将 assets/rime 部署到内部存储并记录版本；`RimeConfigManager` 封装 JNI 层 `RimeConfig` 的读写 API，统一 open/close 生命周期；`DisplayModeManager` 持久化悬浮键盘开关与面板位置；`ThemeManager`（文件不存在但命名约定一致）用于主题切换。
- `level/`：等级系统数据层。`LevelRepository` 是 SharedPreferences 单一数据源，所有写方法加 `@Synchronized`；`LevelStats` 是热路径计数器，基于 `AtomicInteger` 防抖批量落盘，避免在输入热路径写磁盘。

依赖方向单向：`ui → config` / `ui → level` / `level → core.level.LevelEngine`，UI 不直接调用 JNI，而是通过 `AppContainer` 或 Repository 间接访问。
