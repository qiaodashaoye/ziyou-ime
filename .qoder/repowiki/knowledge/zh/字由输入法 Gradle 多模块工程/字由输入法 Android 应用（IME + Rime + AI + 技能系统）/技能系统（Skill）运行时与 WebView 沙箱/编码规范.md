- 所有 JS→原生 API 调用统一走 `SkillBridge.postMessage` 单入口，消息体固定为 `{callId, method, params}` 三元组，禁止直接暴露多个 `@JavascriptInterface` 方法。
- 运行时方法按功能分组命名：`storage.*`、`image.*`、`ui.*`、`input.*`、`clipboard.*`，通过 `method.startsWith(...)` 前缀分发到对应处理器。
- 权限校验集中通过 `requirePermission(SkillPermission.XXX)` 在方法入口处检查 manifest 声明，失败抛出 `SkillApiException` 透传给脚本 reject。
- 异步操作统一使用 `runtimeScope.launch { withContext(storageContext|Dispatchers.IO) { ... } }` 模式，确保 IO 不阻塞主线程且顺序可预测。
- 资源路径访问前必须经 `ZipEntryValidator.isSafeRelativePath` 校验，读取时二次 canonicalPath 比对防止目录穿越。
- 错误统一包装为 `SkillApiException(message)` 或 `IllegalArgumentException`，Bridge 层捕获后转换为 `{message}` JSON 字符串返回脚本侧。
