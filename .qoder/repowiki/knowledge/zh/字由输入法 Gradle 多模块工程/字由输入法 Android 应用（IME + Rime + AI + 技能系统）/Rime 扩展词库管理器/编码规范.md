- 所有耗时 IO 操作（网络下载、文件读写、JSON 解析）统一通过 `withContext(Dispatchers.IO)` 包裹，避免阻塞主线程。
- 外部不可信输入（catalog id、URL、文件大小）在进入系统前必须经过白名单或正则校验（如 `RemoteDictInfo.isValidId`、`ALLOWED_HOSTS`、`MAX_DICT_BYTES`），非法值直接丢弃而非传播。
- 数据模型以 data class 表达，状态类统一采用 sealed class + data object/data class 子类型模式（`DownloadState`、`DeployState`、`PreviewState`）。
- 日志输出统一使用 `Log.i` / `Log.w` / `Log.e` 配合固定 `TAG` 常量，异常路径均记录堆栈信息。
- YAML 词库文件的解析遵循相同模式：先扫描至 `...` 标记进入正文，再逐行跳过空行与注释，按 Tab 分割提取词条。
