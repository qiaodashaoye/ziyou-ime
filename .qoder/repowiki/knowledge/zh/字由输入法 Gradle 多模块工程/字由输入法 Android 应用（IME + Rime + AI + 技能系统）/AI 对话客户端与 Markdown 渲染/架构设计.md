本模块由三个 Kotlin 文件组成，职责清晰且单向依赖：
- `AiConfig.kt`：通过 SharedPreferences（`ziyou_ai`）持久化 API URL、API Key、模型名，并提供默认值（阿里云百炼 DashScope），是纯配置层。
- `AiChatClient.kt`：核心单例对象，封装 OpenAI 兼容的 `chat/completions` 非流式请求，使用原生 `HttpURLConnection` 发起 HTTPS 调用，强制 Bearer 鉴权、连接/读取超时与响应体大小上限（1MB），所有 IO 切到 `Dispatchers.IO`；依赖 `AiConfig` 获取端点与密钥，暴露 `ask()` 协程方法与 `BASE_SYSTEM_PROMPT` 常量供上层组合 system prompt。
- `MarkdownRenderer.kt`：纯函数式渲染器，将 Markdown 子集解析为 `SpannableStringBuilder`，通过注入的 `Palette` 数据类与主题解耦，不依赖任何第三方库。
依赖方向：`AiChatClient` → `AiConfig`；`MarkdownRenderer` 独立无外部依赖；三者均位于 `com.ziyou.ime.ai` 包内，对外仅暴露公开 API。
