- 配置项统一通过 `object` 单例 + `SharedPreferences` 存取，并提供 `get*` 方法配合默认值回退模式。
- 网络请求统一使用 `withContext(Dispatchers.IO)` 切换线程，并通过 `Result<T>` 返回成功/失败结果而非抛出异常。
- HTTP 安全基线一致：强制 HTTPS 协议校验、设置连接/读取超时、限制响应体大小、Bearer Token 鉴权头。
- Markdown 渲染采用注入式 `Palette` 数据类传递主题色，使渲染器与 UI 主题层完全解耦。
- 正则表达式集中定义在文件顶部常量区（如 `HEADING`、`INLINE`、`FENCE` 等），便于维护与复用。
