模块采用三层分离架构：
- Kotlin 接口层：`RimeApi` 定义所有 suspend 函数 API，`SimpleRimeImpl` 实现并通过 `RimeDispatcher`（单线程 Executor + CoroutineDispatcher）保证所有调用串行化，屏蔽 librime 非线程安全特性。
- JNI 桥接层：`RimeNative.kt` 声明 `external` 方法，`RimeConfig.kt` 暴露配置文件操作；C++ 侧 `rime_jni.cc` 以单例 `Rime` 类封装引擎生命周期，`config.cc` 独立处理配置读写，通过 `jni-utils.h` 中的 `GlobalRefSingleton` 缓存 Java 类/方法 ID，避免重复查找。
- 数据模型层：`ProtoTypes.kt` 定义 Commit/Context/Status/Candidate 等 data class，与 C++ `helper-types.h` 中的同名结构体一一对应，由 `objconv.h` 的转换函数完成双向序列化。
- 消息通道：JNI 回调通过 `RimeNative.handleRimeMessage` 转发到 `RimeMessageHandler`，以 `SharedFlow<RimeMessage>` 广播 schema/option/deploy 事件给 UI 订阅者。
- 构建：`CMakeLists.txt` 将 `librime.a` 静态链接为 `rime_jni.so`，支持 WITH_LUA/WITH_OCTAGRAM/WITH_PREDICT/WITH_OPENCC 可选模块开关。
