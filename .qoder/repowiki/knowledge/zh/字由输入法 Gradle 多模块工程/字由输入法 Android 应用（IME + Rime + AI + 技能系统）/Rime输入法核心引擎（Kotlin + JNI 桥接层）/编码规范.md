- 所有 Rime 引擎调用必须通过 `RimeDispatcher.dispatch { ... }` 在专属单线程执行，禁止直接调用 `RimeNative` 外部方法。
- JNI 外部方法统一使用 `@JvmStatic external fun` 声明，并在 `RimeNative` 或 `RimeConfig` 中按功能分组注释。
- C++ 侧对 JNI 局部引用、字符串、JavaVM 环境均使用 RAII 包装类（`JRef`、`CString`、`JString`、`JEnv`）自动释放资源。
- C++ Proto 类型与 Kotlin data class 保持字段名一一对应，通过 `objconv.h` 中的 `rimeXxxToJObject` 系列函数完成序列化。
- JNI 回调错误通过 `env->ExceptionCheck()` 检查并 `ExceptionClear()` 清理，防止异常传播导致崩溃。
- 热路径（按键处理）优先使用批量接口（如 `processRimeKeyBulk`、`getRimeBulkCandidates`）减少 JNI 跨界次数。
