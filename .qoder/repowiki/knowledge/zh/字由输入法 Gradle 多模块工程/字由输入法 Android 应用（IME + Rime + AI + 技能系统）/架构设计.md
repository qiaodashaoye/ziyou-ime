app 模块是 Android Application 入口（ZiyouApplication），以 `com.ziyou.ime.di.AppContainer` 为依赖注入中心，将 core_rime（RimeDispatcher/RimeNative）、input_method_engine（ZiYouInputMethodService 及各类 KeyboardView）、ai_features（AiChatClient/MarkdownRenderer）、dictionary_manager（DictManager/DictDownloader）、skill_system（SkillManager/SkillRuntime）和 ui_settings（SettingsActivity/LevelActivity）等子模块装配在一起。
- 启动流程：Application.onCreate() 仅保存全局实例；Rime 引擎初始化与资源部署延迟到 RimeSession.initialize() 异步执行，避免阻塞主线程。
- JNI 桥接：CMakeLists.txt 指向 src/main/jni/librime_jni，构建时启用 WITH_PREDICT=ON，NDK ABI 通过 -Pziyou.abis 参数控制。
- 资产同步：build.gradle.kts 中自定义 SyncSkillDevGuideTask 在构建期把 docs/技能插件开发指南.md 拷贝至 assets/docs/skill_dev_guide.md，作为单一来源。
- 测试：unit test 使用 JUnit + MockK + Coroutines Test，instrumented test 使用 Compose UI Test + Espresso，并通过 FakeRimeEngine 隔离 native 依赖。
