- 输入键类型通过 Kotlin sealed class `InputKey` 及其 data class/data object 子类（T9Key、Apostrophe、PinyinKey、ConfirmedKey）统一表示，按模式匹配处理分支。
- 状态机方法对非法或不匹配输入返回 null 或 false，且保证不修改已有记录，调用方负责降级处理。
- 字符偏移计算通过统一的 `widthOf()` 和 `charOffsetBefore()` 私有方法累加，确保已确认段宽度按合并前原始记录计算。
- 工具类采用 object 单例 + 静态 init 块预建映射表，对外 API 统一以数字键为规范表示，内部再转换为组代表字母查表。
