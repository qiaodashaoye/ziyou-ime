该模块是纯 Kotlin 逻辑层，不包含任何 Android/JSON/IO 依赖，职责按文件清晰拆分：
- `SkillManifest.kt`：定义 `SkillManifest` data class 和 `SkillPanelMode` 枚举，作为 manifest.json 的纯数据模型。
- `SkillPermission.kt`：定义宿主预定义的权限枚举（network、clipboard_read/write、storage、image），通过 `fromId` 反向解析。
- `SkillManifestValidator.kt`：单例校验器，集中校验 manifest 各字段（id 格式、版本语义、minHostApi 兼容性、entry 路径、networkDomains 白名单等），返回错误列表供上层展示。
- `SkillVersionComparator.kt`：数字点分版本号的数值比较与升级判定（防降级替换攻击）。
- `ZipEntryValidator.kt`：Zip Slip 防护，限制包大小、条目数、路径长度，并拒绝 `../` 等逃逸路径。
依赖方向单向：校验器依赖数据模型和 ZipEntryValidator；SkillVersionComparator 独立无依赖。测试位于同包下对应 `*Test.kt` 文件。
