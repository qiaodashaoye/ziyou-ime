模块采用 com.ziyou.ime.core.<feature> 的扁平包结构，每个子目录对应一个独立能力域：clipboard（剪贴板历史）、floating（悬浮面板几何）、image（图片支持策略）、level（等级引擎）、markdown（简易 Markdown 解析）、rag（BM25 检索与提示词构建）、routing（启动路由）、skill（技能包元数据与校验）、skin（皮肤规范与解析）、t9（九宫格状态机）、toolbar（工具栏配置）、userdict（用户词典）。所有子能力均为纯 Kotlin 代码，不依赖任何 Android framework 类型，仅通过 build.gradle.kts 声明 junit 测试依赖；上层 :app 通过编译器强制的单向依赖方向消费这些能力，形成清晰的边界隔离。
