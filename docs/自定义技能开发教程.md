# 字由输入法 · 自定义技能开发教程

> 本教程面向想要为字由输入法开发自定义技能的用户。无需 Android 开发经验，只需掌握基础 HTML + JavaScript 即可。

---

## 快速开始

一个技能 = 一个文件夹（HTML + JS），打包后导入输入法即可使用。

**最小可运行技能只需两个文件：**

```
com.user.hello/
├── manifest.json   ← 技能信息（必需）
└── index.html      ← 界面和逻辑（必需）
```

30 秒体验：创建上面两个文件 → 打包 → 导入 → 打开键盘点「技」→ 看到你的技能。

---

## 1. 技能包结构

```
com.user.myskill/
├── manifest.json     # 技能元数据（必需）
├── index.html        # 入口页面（必需，文件名可自定义，由 manifest.entry 指定）
├── script.js         # 逻辑代码（可选，也可内联在 html 中）
└── assets/           # 图片等静态资源（可选）
    └── bg.png
```

**基本约束：**

- 包总大小 ≤ 5MB，文件数 ≤ 200
- 所有文件使用包内相对路径，不允许 `../` 或绝对路径
- 页面中引用资源用相对路径（如 `<img src="assets/bg.png">`）
- **不支持外部 CDN 链接**——所有 JS/CSS/图片必须打进包内

## 2. manifest.json 详解

manifest.json 描述技能的基本信息和权限需求：

```json
{
  "manifest_version": 1,
  "id": "com.user.weather",
  "name": "天气查询",
  "version": "1.0.0",
  "min_host_api": 1,
  "author": "你的名字",
  "description": "选择城市，查询天气并发送",
  "icon_text": "🌤",
  "entry": "index.html",
  "panel_mode": "embed",
  "permissions": ["network", "storage"],
  "network_domains": ["wttr.in"]
}
```

### 必需字段

| 字段 | 说明 | 规则 |
|------|------|------|
| `manifest_version` | 固定填 `1` | — |
| `id` | 技能唯一标识 | 反向域名格式，全小写，至少两段（如 `com.user.myskill`） |
| `name` | 显示名称 | ≤30 字符 |
| `version` | 版本号 | 纯数字点分格式（如 `1.0.0`），不支持 `-beta` 后缀 |
| `min_host_api` | 所需最低宿主版本 | 一般填 `1`；用到 fetch/clipboard/input 填 `2`；用到 image 填 `3` |
| `entry` | 入口文件路径 | 必须以 `.html` 结尾 |

### 可选字段

| 字段 | 说明 |
|------|------|
| `author` | 作者名 |
| `description` | 一句话描述 |
| `icon_text` | 技能图标（emoji 或单字），显示在技能列表中 |
| `panel_mode` | `embed`（默认，工具型）或 `card`（信息卡片，点击结果上屏后收起） |
| `permissions` | 权限列表，见下表 |
| `network_domains` | 网络请求域名白名单（≤10 个），仅 `network` 权限时使用 |
| `needs_input` | 设为 `true` 时可在面板内使用键盘打字（见第 5 节） |

### 可用权限

| 权限 | 用途 |
|------|------|
| （无需声明） | sendText、getContext、getLocale、haptic、ui 控制 |
| `storage` | 本地数据持久化 |
| `network` | 网络请求（需配合 `network_domains` 白名单） |
| `clipboard_read` | 读取剪贴板 |
| `clipboard_write` | 写入剪贴板 |
| `image` | 发送图片到输入框 / 保存到相册 |

> 注意：声明了不存在的权限名会导致技能无法加载。

## 3. IMESkill API 参考

宿主在页面中注入全局对象 `window.IMESkill`，所有 API 均返回 Promise。

```javascript
IMESkill.apiVersion   // 当前宿主 API 版本号（同步属性）
```

### 3.1 sendText — 发送文本到输入框

```javascript
await IMESkill.sendText('你好，世界！');
```

- 文本发送到用户当前正在输入的编辑框
- 发送后技能面板自动关闭
- 限制：非空，≤5000 字符

### 3.2 getContext — 获取当前环境

```javascript
const ctx = await IMESkill.getContext();
// { packageName: 'com.tencent.mm', inputType: 'text' }
```

- `packageName`：当前前台应用包名
- `inputType`：`text` / `number` / `phone` / `datetime`

### 3.3 getLocale / haptic — 语言与震动

```javascript
const locale = await IMESkill.getLocale();  // 'zh-CN'
IMESkill.haptic();                          // 触发一次按键震动
```

### 3.4 ui — 面板控制

```javascript
await IMESkill.ui.setTitle('天气 · 北京');  // 设置顶部标题（≤20 字符）
await IMESkill.ui.close();                  // 关闭面板

// 以下仅 needs_input 技能可用：
await IMESkill.ui.setExpanded(false);       // 收缩键盘，面板接管全部空间（展示长内容）
await IMESkill.ui.setExpanded(true);        // 恢复完整键盘界面
await IMESkill.ui.setPanelHeight(1.0);      // 自定义面板高度（0.4~1.2，默认 0.6）
```

### 3.5 storage — 本地存储（需 `storage` 权限）

```javascript
await IMESkill.storage.set('city', '北京');
const city = await IMESkill.storage.get('city');   // 无此 key 返回 null
await IMESkill.storage.remove('city');
```

- 每个技能独立存储空间，互不可见
- 总量限额 1MB
- 复杂对象请自行 `JSON.stringify` / `JSON.parse`
- `localStorage` 不可用，持久化只能用此 API

### 3.6 fetch — 网络请求（需 `network` 权限）

```javascript
const resp = await IMESkill.fetch('https://wttr.in/Beijing?format=3');
// resp = { status: 200, body: 'Beijing: ⛅️ +11°C' }

// POST 请求
await IMESkill.fetch('https://api.example.com/v1', {
  method: 'POST',
  body: JSON.stringify({ q: 'hello' }),
  contentType: 'application/json'
});
```

**使用须知：**

- 必须 HTTPS，域名必须在 `network_domains` 白名单中
- 超时 10 秒，响应 ≤1MB
- 频率限制：≤30 次/分钟，并发 ≤2
- 不会自动跟随重定向（3xx 原样返回）

### 3.7 clipboard — 剪贴板（需对应权限）

```javascript
const text = await IMESkill.clipboard.read();    // 需 clipboard_read，无内容返回 null
await IMESkill.clipboard.write('复制的内容');      // 需 clipboard_write
```

### 3.8 input — 面板内打字（需 `needs_input: true`）

```javascript
await IMESkill.input.requestFocus('my-input');   // 键盘文本流入 #my-input
await IMESkill.input.releaseFocus();             // 恢复文本到宿主应用
```

### 3.9 image — 图片输出（需 `image` 权限）

```javascript
const url = canvas.toDataURL('image/png');  // 仅支持 PNG

await IMESkill.image.send(url);             // 发送到当前输入框
await IMESkill.image.saveToGallery(url);    // 保存到系统相册
```

- 仅支持 PNG 格式
- `send` 需要接收方编辑框支持图片（如微信聊天框）
- `saveToGallery` 需 Android 10+
- base64 数据 ≤512KB

## 4. 开发环境搭建与调试

### 4.1 浏览器预调（推荐起步方式）

技能就是标准 HTML + JS，可以先在电脑浏览器里开发调试。在页面头部加入 mock 垫片模拟宿主环境：

```html
<script>
  // 仅本地浏览器调试用：真机上宿主注入的 IMESkill 已存在，此段不生效
  if (!window.IMESkill) {
    window.IMESkill = {
      apiVersion: 1,
      sendText: t => (console.log('[sendText]', t), Promise.resolve()),
      getContext: () => Promise.resolve({ packageName: 'debug', inputType: 'text' }),
      getLocale: () => Promise.resolve(navigator.language),
      haptic: () => Promise.resolve(),
      ui: { setTitle: t => Promise.resolve(), close: () => Promise.resolve(),
            setExpanded: v => Promise.resolve(), setPanelHeight: r => Promise.resolve() },
      storage: {
        get: k => Promise.resolve(localStorage.getItem('sk_' + k)),
        set: (k, v) => Promise.resolve(localStorage.setItem('sk_' + k, v)),
        remove: k => Promise.resolve(localStorage.removeItem('sk_' + k))
      },
      clipboard: {
        read: () => navigator.clipboard.readText(),
        write: t => navigator.clipboard.writeText(t)
      },
      input: {
        requestFocus: id => Promise.resolve(),
        releaseFocus: () => Promise.resolve()
      },
      image: {
        send: b64 => (console.log('[image.send]', b64.length), Promise.resolve()),
        saveToGallery: b64 => (console.log('[image.saveToGallery]', b64.length), Promise.resolve())
      },
      fetch: (url) => fetch(url).then(r => r.text().then(body => ({ status: r.status, body: body })))
    };
  }
</script>
```

### 4.2 真机调试（Chrome DevTools）

debug 版输入法支持 WebView 远程调试：

1. 手机连接电脑，打开技能面板进入你的技能
2. 电脑 Chrome 访问 `chrome://inspect/#devices`
3. 找到技能页面，点 **inspect** 即可断点、看 console、改样式

查看加载错误日志：

```bash
adb logcat -s SkillManager SkillBridge
```

### 4.3 面板尺寸适配建议

- 用 `flex` / `grid` 纵向自适应布局，不要写死高度
- 页面顶部两角有宿主悬浮按钮（左侧约 90px、右侧约 40px），避免放置关键按钮
- 根字号 14~17px，按钮触摸目标 ≥40px
- 内容超出时加 `overflow-y: auto`
- 背景建议 `transparent` 或半透明灰，自动融入键盘主题

## 5. 面板内文本输入（进阶）

如果你的技能需要用户输入自由文本（如搜索框），需要：

1. manifest 中声明 `"needs_input": true`
2. 用户点击输入框时调用 `IMESkill.input.requestFocus('输入框id')`
3. 此后键盘打字（含中文候选）会流入该输入框
4. 完成后调用 `IMESkill.input.releaseFocus()` 恢复正常

**典型交互流程（输入 → 查询 → 展示 → 发送）：**

```javascript
// ① 点击输入框 → 申请输入路由
input.addEventListener('click', () => {
  IMESkill.input.requestFocus('my-input');
});

// ② 点击查询按钮 → 释放路由，执行查询
goBtn.addEventListener('click', () => {
  IMESkill.input.releaseFocus();
  doQuery();
});

// ③ 展示结果 → 收缩键盘，面板接管空间
function showResult(data) {
  renderUI(data);
  IMESkill.ui.setExpanded(false);
}

// ④ 发送结果 → 直达聊天框，面板自动关闭
sendBtn.addEventListener('click', () => {
  IMESkill.sendText(resultText);
});
```

> 提示：能用按钮/预设选项解决的场景，不建议用 `needs_input`（面板更大、交互更简单）。

**script.js：**

```javascript
'use strict';
var expr = '';
var display = document.getElementById('display');

function render() { display.textContent = expr === '' ? '0' : expr; }

// 四则运算求值（不使用 eval）
function evaluate(input) {
  var tokens = input.match(/(\d+\.?\d*|[+\-*/])/g);
  if (!tokens) return null;
  var values = [], ops = [];
  var prec = { '+': 1, '-': 1, '*': 2, '/': 2 };
  function apply() {
    var op = ops.pop(), b = values.pop(), a = values.pop();
    if (a === undefined || b === undefined) throw new Error('bad');
    if (op === '+') values.push(a + b);
    else if (op === '-') values.push(a - b);
    else if (op === '*') values.push(a * b);
    else { if (b === 0) throw new Error('div0'); values.push(a / b); }
  }
  var expectNum = true;
  for (var i = 0; i < tokens.length; i++) {
    var t = tokens[i];
    if (prec[t]) {
      if (expectNum && t === '-') { tokens[i + 1] = '-' + tokens[i + 1]; continue; }
      if (expectNum) throw new Error('bad');
      while (ops.length && prec[ops[ops.length - 1]] >= prec[t]) apply();
      ops.push(t);
      expectNum = true;
    } else {
      values.push(parseFloat(t));
      expectNum = false;
    }
  }
  if (expectNum) throw new Error('bad');
  while (ops.length) apply();
  var result = values.pop();
  if (!isFinite(result)) throw new Error('overflow');
  return parseFloat(result.toFixed(10)).toString();
}

function calc() {
  try {
    var result = evaluate(expr);
    if (result !== null) { expr = result; render(); }
  } catch (e) { display.textContent = '错误'; expr = ''; }
}

document.querySelector('.grid').addEventListener('click', function (e) {
  var k = e.target.getAttribute('data-k');
  if (!k) return;
  IMESkill.haptic();
  if (k === 'C') { expr = ''; render(); }
  else if (k === 'B') { expr = expr.slice(0, -1); render(); }
  else if (k === '=') { calc(); }
  else if (k === 'S') { calc(); if (expr !== '') IMESkill.sendText(expr); }
  else { expr += k; render(); }
});
render();
```

### 7.2 天气查询（network + storage 权限）

展示网络请求、本地存储、域名白名单的使用。

**manifest.json：**

```json
{
  "manifest_version": 1,
  "id": "com.user.weather",
  "name": "天气查询",
  "version": "1.0.0",
  "min_host_api": 2,
  "author": "张三",
  "description": "选择城市查询天气，结果一键发送",
  "icon_text": "🌤",
  "entry": "index.html",
  "panel_mode": "card",
  "permissions": ["network", "storage"],
  "network_domains": ["wttr.in"]
}
```

**index.html：**

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1, user-scalable=no">
<title>天气</title>
<style>
  * { margin: 0; padding: 0; box-sizing: border-box; -webkit-tap-highlight-color: transparent; }
  html, body { height: 100%; background: transparent; font-family: sans-serif; }
  .wrap { display: flex; flex-direction: column; height: 100%; padding: 6px; gap: 6px; }
  .cities { display: grid; grid-template-columns: repeat(4, 1fr); gap: 4px; }
  .cities button { border: none; border-radius: 6px; padding: 8px 0; font-size: 14px;
                   background: rgba(127,127,127,.15); }
  .cities button:active, .cities button.on { background: #1976D2; color: #fff; }
  #result { flex: 1; border-radius: 8px; padding: 10px 12px; font-size: 15px;
            line-height: 1.6; background: rgba(127,127,127,.12); overflow-y: auto; }
  .hint { font-size: 11px; opacity: .55; margin-top: 4px; }
</style>
</head>
<body>
<div class="wrap">
  <div class="cities" id="cities"></div>
  <div id="result">选择城市查询天气</div>
</div>
<script src="script.js"></script>
</body>
</html>
```

**script.js：**

```javascript
'use strict';
var CITIES = ['北京', '上海', '广州', '深圳', '杭州', '成都', '武汉', '西安'];
var CITY_CODE = { '北京': 'Beijing', '上海': 'Shanghai', '广州': 'Guangzhou',
                  '深圳': 'Shenzhen', '杭州': 'Hangzhou', '成都': 'Chengdu',
                  '武汉': 'Wuhan', '西安': 'Xian' };
var resultEl = document.getElementById('result');
var lastText = null;

function renderCities(active) {
  var box = document.getElementById('cities');
  box.innerHTML = '';
  CITIES.forEach(function (city) {
    var btn = document.createElement('button');
    btn.textContent = city;
    if (city === active) btn.className = 'on';
    btn.addEventListener('click', function () {
      IMESkill.haptic();
      IMESkill.storage.set('last_city', city);
      renderCities(city);
      query(city);
    });
    box.appendChild(btn);
  });
}

async function query(city) {
  resultEl.textContent = '查询中…';
  lastText = null;
  try {
    var resp = await IMESkill.fetch(
      'https://wttr.in/' + CITY_CODE[city] + '?format=3&m');
    if (resp.status !== 200) throw new Error('HTTP ' + resp.status);
    lastText = resp.body.trim().replace(CITY_CODE[city], city);
    resultEl.innerHTML = '';
    var line = document.createElement('div');
    line.textContent = lastText;
    var hint = document.createElement('div');
    hint.className = 'hint';
    hint.textContent = '点击发送';
    resultEl.appendChild(line);
    resultEl.appendChild(hint);
  } catch (e) {
    resultEl.textContent = '查询失败：' + e.message;
  }
}

// 点击结果 → 发送到输入框
resultEl.addEventListener('click', function () {
  if (lastText) IMESkill.sendText(lastText);
});

// 恢复上次选择的城市
IMESkill.storage.get('last_city').then(function (saved) {
  var city = saved && CITIES.indexOf(saved) >= 0 ? saved : null;
  renderCities(city);
  if (city) query(city);
}).catch(function () { renderCities(null); });
```

## 8. 更多场景灵感

| 场景 | 所需权限 | 要点 |
|------|---------|------|
| 快捷短语/话术库 | storage | 分组列表 + 点击 sendText |
| 单位/汇率换算 | network（汇率） | 数字按钮自绘，无需 needs_input |
| 翻译工具 | network + storage | 输入路由 + fetch API + setExpanded 展示 |
| 日期/星期计算 | 无 | 纯本地 Date 运算，零权限最简 |
| 剪贴板历史 | clipboard_read + storage | 读取后存 storage，列表点击上屏 |
| 流程图绘制 | storage + image | Canvas 绘图 → image.send 发图 |

## 9. 开发须知

以下是开发过程中需要了解的行为约束：

| 项目 | 说明 |
|------|------|
| 外部链接 | 不可用。所有 JS/CSS/图片必须打包在技能内 |
| eval / new Function | 不可用。需要表达式求值时请手写解析（参考计算器示例） |
| localStorage | 不可用。请使用 `IMESkill.storage` |
| 页面跳转 | 不能跳转到外部 URL |
| 网络请求 | 只能通过 `IMESkill.fetch`，页面自身的 fetch/XHR 不可用 |
| 消息大小 | 单次 API 调用数据 ≤512KB |

## 10. 常见问题

| 问题 | 解决方法 |
|------|---------|
| 技能没出现在列表里 | manifest 校验失败。用 `adb logcat -s SkillManager` 查看原因（常见：id 格式错误、版本号格式错误、entry 路径不对） |
| 输入框点了没反应 | 面板内打字必须声明 `needs_input` + 调用 `input.requestFocus`；或改用按钮交互 |
| 图片/JS 加载不出来 | 外链不可用或路径含 `../`。资源打进包内，使用纯相对路径 |
| `eval is not allowed` | 不支持 eval，改为手写解析逻辑 |
| fetch 报「域名不在白名单」 | `network_domains` 需精确包含请求域名（子域也要单独列出） |
| fetch 报「请求过于频繁」 | 频控 30 次/分钟、并发 ≤2，请加防抖或缓存 |
| 导入提示缺少 manifest.json | 打包时多套了一层文件夹。确保 manifest.json 在 zip 根目录 |
| 导入提示「版本不高于现有版本」 | 同 id 只能升级，递增 version 后重新打包 |
| localStorage 报错 | 不可用，请声明 `storage` 权限并使用 `IMESkill.storage` |
| 修改代码后没生效 | 重新导入（需递增版本号）或重新 adb 侧载，再重新打开面板 |
| sendText 后面板关了 | 这是设计行为——发送即收起。连续发送需重新打开面板 |

## 错误消息速查

当 API 调用失败时，`error.message` 会给出具体原因：

| 错误消息 | 原因 |
|---------|------|
| `权限拒绝：manifest 未声明 xxx` | 调用了未声明权限的 API |
| `域名不在白名单: xxx` | fetch 域名未在 network_domains 中 |
| `仅允许 HTTPS 请求` | fetch 使用了 http:// |
| `请求过于频繁（上限 30 次/分钟）` | 超出频率限制 |
| `并发请求超限（上限 2）` | 同时发起过多请求 |
| `响应超限（上限 1MB）` | 响应体过大 |
| `存储超限（上限 1MB）` | storage 数据总量越界 |
| `文本超长（上限 5000 字符）` | sendText 文本过长 |
| `text 不能为空` | sendText 传了空字符串 |
| `manifest 未声明 needs_input，无法使用面板输入` | 未声明却调了 input.requestFocus |
| `当前输入框不支持接收图片` | 编辑框不接受图片类型 |
| `仅支持 PNG 图片` | image API 传了非 PNG 数据 |
| `未知方法: xxx` | API 名拼写错误或版本不支持 |
