# docs/skills — Skill 配套技术文档分类目录

本目录按**功能类型**分类存放与 Qoder Skill（`.qoder/skills/`）配套的技术文档：
每个 Skill 一份配套文档，记录该工具覆盖的完整流程、格式规范与背景知识；
Skill 本身（SKILL.md + 脚本）住在 `.qoder/skills/<skill-name>/` 随仓库分发。

## 分类约定

| 分类目录 | 覆盖范围 |
|---|---|
| `engine/` | 引擎层工具链：librime / predict.db / 词库构建与部署 |
| `data/` | 数据处理：语料清洗、统计、导出（预留） |
| `release/` | 发布流程：打包、签名、分发（预留） |
| `ui/` | 界面与皮肤、技能插件开发（预留） |

新分类按需新增；一个 Skill 只挂一个主分类，跨类引用用链接表达。

## 索引

| 分类 | 文档 | 对应 Skill | 说明 |
|---|---|---|---|
| engine | [predict.db构建指南.md](engine/predict.db构建指南.md) | `build-predict-db` | 联想词库构建/更新/验收/部署全流程（Skill 化操作） |

## 维护纪律

1. **文档与 Skill 同提交**：修改 Skill 行为时同步更新配套文档（反之亦然），
   一个 commit 内成对变更；
2. **单一事实源**：可执行流程以 Skill 编排脚本为准，文档负责背景、
   格式规范与故障排查，不重复维护两套命令；
3. **版本标识**：每份文档头部标注版本与对应 Skill 名称；Skill 行为变更
   （参数/流程）时递增文档版本并在变更记录追加一行。
