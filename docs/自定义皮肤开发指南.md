# 字由输入法自定义皮肤开发指南

本指南面向希望为字由输入法制作自定义皮肤的用户。皮肤是**纯数据**（JSON 配置 + 图片 + 字体），不包含任何可执行代码，制作简单、安全可控。

---

## 1. 快速开始

一个最简皮肤只需要一个 `skin.json` 文件。以下示例创建一个粉色圆角键盘皮肤：

```json
{
  "specVersion": 1,
  "meta": {
    "id": "com.myname.pink",
    "name": "粉色心情",
    "author": "myname",
    "version": "1.0.0",
    "darkMode": "light"
  },
  "colors": {
    "light": {
      "keyboardBackground": "#FFF0F5",
      "keyBackground": "#FFFFFF",
      "keyTextColor": "#4A2030",
      "keyPressedBackground": "#FFDDE8",
      "candidateHighlightColor": "#FF69B4"
    }
  },
  "dimens": {
    "keyCornerRadiusDp": 12.0
  }
}
```

将上面的内容保存为 `skin.json`，打包为 `.zyskin` 文件即可导入使用（见[第 5 节](#5-打包与安装)）。

**所有样式字段都是可选的**——未声明的字段自动使用系统默认值，不会导致错误。你只需要写出想改的部分。

---

## 2. 皮肤包文件结构

`.zyskin` 文件本质是一个 **zip 压缩包**（只是扩展名改为 `.zyskin`），内部结构如下：

```
com.myname.pink.zyskin          ← 文件名建议与皮肤 id 一致
├── skin.json                   ← 必需，皮肤配置文件（UTF-8 编码）
├── preview.png                 ← 可选，预览图（建议 720×480 像素）
├── images/                     ← 可选，背景图片目录
│   ├── bg.png
│   └── bg_dark.png
└── fonts/                      ← 可选，自定义字体目录
    └── custom.ttf
```

| 文件/目录 | 是否必需 | 说明 |
|-----------|---------|------|
| `skin.json` | **必需** | 皮肤的全部配置，UTF-8 编码的 JSON 文件 |
| `preview.png` | 可选 | 皮肤管理页展示的预览缩略图，建议 720×480 像素、≤ 300KB。不提供时系统自动生成 |
| `images/` | 可选 | 存放键盘背景图片（支持 png / jpg / jpeg / webp） |
| `fonts/` | 可选 | 存放自定义字体文件（支持 ttf / otf，单个 ≤ 5MB） |

## 3. skin.json 完整字段说明

### 3.1 顶层结构

```json
{
  "specVersion": 1,
  "meta": { ... },
  "colors": { ... },
  "dimens": { ... },
  "typography": { ... },
  "effects": { ... },
  "background": { ... },
  "toolbar": { ... }
}
```

| 节点 | 是否必需 | 说明 |
|------|---------|------|
| `specVersion` | **必需** | 规格版本号，当前固定填 `1` |
| `meta` | **必需** | 皮肤基本信息（id、名称、作者等） |
| `colors` | 可选 | 配色方案 |
| `dimens` | 可选 | 尺寸参数（圆角、间距等） |
| `typography` | 可选 | 字体参数（字号、粗体、自定义字体） |
| `effects` | 可选 | 视觉效果（按键风格、阴影、透明度） |
| `background` | 可选 | 键盘背景图片 |
| `toolbar` | 可选 | 候选区工具栏样式 |

### 3.2 `meta` — 皮肤基本信息

```json
"meta": {
  "id": "com.myname.pink",
  "name": "粉色心情",
  "author": "myname",
  "version": "1.0.0",
  "minSpecVersion": 1,
  "darkMode": "light"
}
```

| 字段 | 是否必需 | 说明 |
|------|---------|------|
| `id` | **必需** | 皮肤唯一标识符。只能使用小写字母、数字、下划线、点号，长度 3–64 位。不能以 `builtin.` 开头（这是内置皮肤保留前缀）。建议使用反向域名格式，如 `com.yourname.skinname` |
| `name` | **必需** | 皮肤展示名称，显示在皮肤管理页 |
| `author` | 可选 | 作者名 |
| `version` | 可选 | 版本号，默认 `"1.0.0"` |
| `minSpecVersion` | 可选 | 要求的最低规格版本，默认 `1` |
| `darkMode` | 可选 | 深浅色模式，见下表。默认 `"light"` |

**darkMode 取值：**

| 值 | 含义 |
|----|------|
| `"light"` | 仅浅色配色。深色系统下仍显示浅色外观 |
| `"dark"` | 仅深色配色。浅色系统下仍显示深色外观 |
| `"both"` | 双套配色，跟随系统深浅色自动切换。**选此项时必须同时提供 `colors.light` 和 `colors.dark`** |

### 3.3 `colors` — 配色方案

配色分为 `light`（浅色）和 `dark`（深色）两套。所有颜色值格式为 `"#RRGGBB"` 或 `"#AARRGGBB"`（带透明度）。

```json
"colors": {
  "light": {
    "keyboardBackground":      "#F5F5F5",
    "keyBackground":           "#FFFFFF",
    "keyTextColor":            "#212121",
    "keyPressedBackground":    "#E0E0E0",
    "funcKeyBackground":       "#E8E8E8",
    "candidateBackground":     "#FFFFFF",
    "candidateTextColor":      "#212121",
    "candidateHighlightColor": "#1976D2",
    "preeditTextColor":        "#424242",
    "borderColor":             "#BDBDBD",
    "keyShadowColor":          "#22000000",
    "toolbarBackground":       "#FFFFFF",
    "toolbarButtonBackground": "#F0F0F0",
    "toolbarTextColor":        "#212121"
  },
  "dark": {
    "...同结构..."
  }
}
```

**颜色字段说明：**

| 字段 | 控制区域 | 缺省行为 |
|------|---------|---------|
| `keyboardBackground` | 键盘整体底板颜色 | 使用系统默认色 |
| `keyBackground` | 普通按键（字母/数字键）的键面颜色 | 使用系统默认色 |
| `keyTextColor` | 按键上的文字颜色 | 使用系统默认色 |
| `keyPressedBackground` | 按键被按下时的键面颜色 | 使用系统默认色 |
| `funcKeyBackground` | 功能键（Shift、删除、空格、回车等）的键面颜色 | 不填时自动由 `keyBackground` 和 `borderColor` 混合生成 |
| `candidateBackground` | 候选词栏背景色 | 使用系统默认色 |
| `candidateTextColor` | 候选词文字颜色 | 使用系统默认色 |
| `candidateHighlightColor` | 当前选中候选词的高亮颜色 | 使用系统默认色 |
| `preeditTextColor` | 编码区（拼音输入中的字母）文字颜色 | 使用系统默认色 |
| `borderColor` | 按键边框/描边颜色 | 使用系统默认色 |
| `keyShadowColor` | 按键阴影颜色（`#AARRGGBB` 格式，AA 为透明度） | 使用系统默认色 |
| `toolbarBackground` | 工具栏（候选区上方功能按钮栏）背景色 | 不填时沿用 `candidateBackground` |
| `toolbarButtonBackground` | 工具栏按钮底色 | 不填时自动由 `toolbarBackground` 和 `borderColor` 混合生成 |
| `toolbarTextColor` | 工具栏文字颜色 | 不填时沿用 `candidateTextColor` |

> **提示**：所有颜色字段都是可选的。你可以只写想改的颜色，其余保持默认。

### 3.4 `dimens` — 尺寸参数

控制键盘的物理尺寸比例，单位为 dp（密度无关像素）。

```json
"dimens": {
  "keyCornerRadiusDp": 8.0,
  "keyGapDp": 4.0,
  "keyboardPaddingDp": 6.0,
  "keyHeightScale": 1.0,
  "keyBorderWidthDp": 0.0
}
```

| 字段 | 含义 | 取值范围 | 默认值 |
|------|------|---------|--------|
| `keyCornerRadiusDp` | 按键圆角半径 | 0 – 24 | 5 |
| `keyGapDp` | 按键之间的间距 | 0 – 12 | 3 |
| `keyboardPaddingDp` | 键盘整体内边距 | 0 – 16 | 3 |
| `keyHeightScale` | 按键高度倍率（1.0 = 标准高度） | 0.8 – 1.3 | 1.0 |
| `keyBorderWidthDp` | 按键描边宽度（0 = 不描边） | 0 – 4 | 0 |

### 3.5 `typography` — 字体参数

```json
"typography": {
  "keyTextSizeSp": 20.0,
  "funcTextSizeSp": 14.0,
  "candidateTextSizeSp": 18.0,
  "preeditTextSizeSp": 16.0,
  "fontFamily": "fonts/custom.ttf",
  "keyTextBold": false
}
```

| 字段 | 含义 | 取值范围 | 默认值 |
|------|------|---------|--------|
| `keyTextSizeSp` | 按键文字字号 | 8 – 32 | 18 |
| `funcTextSizeSp` | 功能键文字字号 | 8 – 32 | 12 |
| `candidateTextSizeSp` | 候选词字号 | 8 – 32 | 16 |
| `preeditTextSizeSp` | 编码区字号 | 8 – 32 | 12 |
| `fontFamily` | 自定义字体文件路径（包内相对路径） | 必须指向包内 `fonts/` 下的 ttf/otf 文件 | 系统默认字体 |
| `keyTextBold` | 按键文字是否加粗 | true / false | false |

### 3.6 `effects` — 视觉效果

```json
"effects": {
  "keyStyle": "filled",
  "keyShadow": { "enabled": true, "radiusDp": 2.0, "dxDp": 0.0, "dyDp": 1.0 },
  "backgroundAlpha": 1.0
}
```

| 字段 | 含义 | 取值 | 默认值 |
|------|------|------|--------|
| `keyStyle` | 按键渲染风格 | 见下表 | `"filled"` |
| `keyShadow` | 按键阴影参数 | 见下表 | 开启，向下偏移 1dp |
| `backgroundAlpha` | 键面整体透明度（背景图透出效果） | 0.3 – 1.0 | 1.0（完全不透明） |

**keyStyle 取值：**

| 值 | 效果 |
|----|------|
| `"filled"` | 填充键面（默认，标准外观） |
| `"outline"` | 仅描边、无填充（线框风格） |
| `"flat"` | 无键面、纯文字（极简风格，类似 Gboard 无边框） |

**keyShadow 子字段：**

| 字段 | 含义 | 取值范围 | 默认值 |
|------|------|---------|--------|
| `enabled` | 是否启用阴影 | true / false | true |
| `radiusDp` | 阴影模糊半径（越大越柔和） | 0 – 8 | 0 |
| `dxDp` | 阴影水平偏移 | -4 – 4 | 0 |
| `dyDp` | 阴影垂直偏移（正值向下） | -4 – 4 | 1 |

### 3.7 `background` — 键盘背景图片

```json
"background": {
  "image": "images/bg.png",
  "imageDark": "images/bg_dark.png",
  "scaleMode": "centerCrop",
  "dimAmount": 0.0
}
```

| 字段 | 含义 | 取值 | 默认值 |
|------|------|------|--------|
| `image` | 背景图片路径（包内相对路径） | 必须指向包内实际存在的 png/jpg/jpeg/webp 文件 | 无（纯色背景） |
| `imageDark` | 深色模式专用背景图 | 同上。不填时深色模式沿用 `image` | 沿用 `image` |
| `scaleMode` | 图片缩放模式 | 见下表 | `"centerCrop"` |
| `dimAmount` | 背景图上的压暗遮罩强度（保证按键文字可读） | 0 – 0.7 | 0 |

**scaleMode 取值：**

| 值 | 效果 |
|----|------|
| `"centerCrop"` | 等比缩放填满整个键盘区域，超出部分裁掉（推荐，不变形） |
| `"fitXY"` | 拉伸填满整个区域（可能变形，适合尺寸精确匹配的背景图） |
| `"tile"` | 原始尺寸平铺（适合小纹理/图案） |

> **提示**：如果背景图较花哨，建议设置 `dimAmount` 为 0.2–0.4，在图上叠加一层半透明黑色遮罩，确保按键文字清晰可读。

### 3.8 `toolbar` — 工具栏样式

控制候选区上方的功能按钮栏（包含候选词翻页、设置快捷入口等按钮）。

```json
"toolbar": {
  "buttonCornerRadiusDp": 12.0,
  "buttonShadow": true,
  "buttonBorderWidthDp": 0.0,
  "buttonSpacingDp": 5.0,
  "textSizeSp": 14.0,
  "textBold": true,
  "showDivider": true
}
```

| 字段 | 含义 | 取值范围 | 默认值 |
|------|------|---------|--------|
| `buttonCornerRadiusDp` | 工具栏按钮圆角 | 0 – 24 | 胶囊形（全圆角） |
| `buttonShadow` | 按钮是否带投影 | true / false | false |
| `buttonBorderWidthDp` | 按钮描边宽度 | 0 – 4 | 0 |
| `buttonSpacingDp` | 按钮之间的间距 | 0 – 12 | 5 |
| `textSizeSp` | 工具栏文字字号 | 8 – 32 | funcTextSizeSp + 2 |
| `textBold` | 工具栏文字是否加粗 | true / false | true |
| `showDivider` | 工具栏与键盘区之间是否显示分隔线 | true / false | true |

> **提示**：想要工具栏与键盘融为一体（无分隔线、按钮与按键同风格），可设置 `"showDivider": false` 并让 `toolbarBackground` 与 `keyboardBackground` 同色。

## 4. 开发步骤

### 第一步：创建皮肤目录

```bash
mkdir com.myname.pink
cd com.myname.pink
```

目录名建议与皮肤 `meta.id` 保持一致。

### 第二步：编写 skin.json

在目录中创建 `skin.json`，写入皮肤配置。最简配置只需 `specVersion` + `meta`：

```json
{
  "specVersion": 1,
  "meta": {
    "id": "com.myname.pink",
    "name": "粉色心情",
    "author": "myname",
    "darkMode": "light"
  }
}
```

然后逐步添加 `colors`、`dimens`、`effects` 等节点，调出满意的效果。

### 第三步：添加资源（可选）

- **背景图**：放入 `images/` 目录，在 `background.image` 中引用
- **自定义字体**：放入 `fonts/` 目录，在 `typography.fontFamily` 中引用
- **预览图**：制作一张 720×480 的 `preview.png` 放在根目录（可选，不提供时系统自动生成）

### 第四步：打包为 .zyskin

`.zyskin` 就是 zip 格式。打包时**只包含皮肤资源文件**，不要包含开发脚本：

```bash
# 方法一：使用 zip 命令
cd com.myname.pink
zip -r ../com.myname.pink.zyskin skin.json preview.png images/ fonts/

# 方法二：如果只有 skin.json（最简皮肤）
zip ../com.myname.pink.zyskin skin.json
```

> **重要**：包内只能包含 `json / png / jpg / jpeg / webp / ttf / otf` 扩展名的文件。包含其他类型文件（如 .py、.sh、.md）会导致整个包被拒绝安装。

### 第五步：导入到输入法

在手机上：**字由输入法设置页 → 外观 → 键盘皮肤 → 导入皮肤包 → 选择 `.zyskin` 文件**。

导入成功后，皮肤会出现在皮肤管理网格中，点击即可应用。

## 5. 打包与安装

### 打包要求

| 约束 | 限制 |
|------|------|
| 包体大小（压缩后） | ≤ 20MB |
| 包内文件数 | ≤ 64 个 |
| 单个文件大小 | ≤ 5MB |
| 解压后总大小 | ≤ 20MB |
| 允许的文件扩展名 | `json` `png` `jpg` `jpeg` `webp` `ttf` `otf` |

### 安装校验

导入时系统会自动校验：

- `skin.json` 格式是否合法、字段是否在允许范围内
- 皮肤 id 是否符合格式要求、是否与已有皮肤冲突
- 引用的背景图/字体文件是否真实存在于包内
- 文件路径是否安全（不允许 `..` 等路径穿越）

校验失败时会显示具体的错误原因列表，根据提示修正后重新打包导入即可。

### 升级皮肤

修改皮肤后重新打包导入，相同 `meta.id` 的皮肤会自动覆盖旧版本（原子替换，失败时保留旧版本）。

### 卸载皮肤

在皮肤管理页长按皮肤卡片即可卸载。卸载当前正在使用的皮肤时，会自动切换回内置默认皮肤。内置皮肤不可卸载。

## 7. 设计建议

### 配色

- **对比度**：确保 `keyTextColor` 与 `keyBackground` 之间有足够对比度，否则按键文字难以辨认
- **功能键区分**：`funcKeyBackground` 建议与 `keyBackground` 有明显色差，帮助用户快速定位功能键
- **高亮色**：`candidateHighlightColor` 建议使用饱和度较高的强调色，让选中候选词一目了然
- **阴影色**：使用带透明度的颜色（如 `#22000000`），前两位 `AA` 是透明度（00 全透明，FF 不透明）

### 深浅色适配

- 如果皮肤只适合一种模式，`darkMode` 设为 `"light"` 或 `"dark"` 即可
- 如果要跟随系统切换，设为 `"both"` 并提供两套配色
- 深色模式下阴影通常需要加重（透明度更高），以补偿暗底对比损失

### 背景图

- 推荐尺寸：宽 1080px 以上，宽高比约 2:1（键盘区域近似比例）
- 背景图较复杂时，设置 `dimAmount: 0.2` ~ `0.4` 提升按键可读性
- 使用 `backgroundAlpha < 1.0` 可让键面半透明，透出背景图效果
- `scaleMode: "centerCrop"` 适合大多数场景（不变形、自动裁切）

### 预览图

- 建议尺寸 720×480 像素，展示键盘整体视觉效果
- 可以用截图工具截取实际键盘效果，或用绘图软件制作
- 不提供预览图时，系统会自动渲染一张缩略图

## 8. 常见问题

**Q：导入时提示"皮肤包条目非法"怎么办？**

检查包内是否包含了不允许的文件类型。皮肤包只允许 `json / png / jpg / jpeg / webp / ttf / otf` 扩展名。开发脚本（.py / .sh）、文档（.md / .txt）等不要打进包里。

**Q：导入时提示"皮肤 id 与内置皮肤冲突"怎么办？**

`meta.id` 不能以 `builtin.` 开头，这是内置皮肤的保留前缀。请使用自己的域名或命名空间。

**Q：导入时提示"引用的资源不存在于包内"怎么办？**

检查 `background.image`、`background.imageDark`、`typography.fontFamily` 中引用的路径是否与实际文件路径完全一致（区分大小写）。

**Q：导入时提示某个字段"超出范围"怎么办？**

检查数值字段是否在允许范围内（参见第 3 节各字段的取值范围列）。超出范围的值会被拒绝。

**Q：皮肤导入后颜色/尺寸不满意，必须重新打包吗？**

不需要。在皮肤管理页点击「自定义当前皮肤」，可以通过滑杆和取色器实时调整圆角、键距、字号、配色、透明度等参数，调整结果作为独立覆盖层保存，不会修改原始皮肤包。随时可以「恢复默认」回到皮肤包原始效果。

**Q：`darkMode: "light"` 的皮肤在深色系统下会怎样？**

皮肤会保持浅色外观不变。用户也可以在输入法设置中强制切换深浅色策略。

**Q：如何让工具栏和键盘看起来融为一体？**

设置 `toolbar.showDivider: false` 去掉分隔线，并让 `toolbarBackground` 与 `keyboardBackground` 使用相同颜色。参考内置"悬浮立体"皮肤的做法。
