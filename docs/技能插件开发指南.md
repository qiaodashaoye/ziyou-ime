## 1. 技能包结构

一个技能插件是一个目录（分发时打包为 `.skill` 后缀的 zip），结构如下：

```
com.user.myskill/
├── manifest.json     # 技能元数据（必需）
├── index.html        # 入口 UI 文件（必需，文件名可自定义，manifest.entry 指定）
├── script.js         # 逻辑代码（可选，也可直接内联在 html 中）
└── assets/           # 图片等静态资源（可选）
    └── bg.png
```

约束：

- 包总大小 ≤ **5MB**，条目数 ≤ **200**；
- 所有文件路径必须是包内相对路径——**不允许** `../`、绝对路径、反斜杠（安装与资源加载时双重校验，违规直接拒绝）；
- 页面内引用资源一律用相对路径（如 `<img src="assets/bg.png">`），外部 URL 会被宿主拦截为空响应（见 §7）。

## 2. manifest.json 字段详解

```json
{
  "manifest_version": 1,
  "id": "com.user.weather",
  "name": "天气查询",
  "version": "1.0.0",
  "min_host_api": 1,
  "author": "张三",
  "description": "选择城市，查询天气并发送",
  "icon_text": "🌤",
  "entry": "index.html",
  "panel_mode": "embed",
  "permissions": ["network", "storage"],
  "network_domains": ["api.weather.example.com"]
}
```

| 字段 | 必需 | 规则 |
|------|:---:|------|
| `manifest_version` | ✅ | 固定为 `1`，其他值拒绝加载 |
| `id` | ✅ | 反向域名风格，全小写，至少两段，字母开头，可含数字/下划线（如 `com.user.weather_v2`）；≤100 字符。id 是技能的唯一标识，storage 隔离、升级覆盖均以 id 为准 |
| `name` | ✅ | 展示名，非空且 ≤30 字符 |
| `version` | ✅ | 数字点分（`1` / `1.0` / `1.0.0`），带字母后缀（`1.0-beta`）非法 |
| `min_host_api` | ✅ | 技能所需最低宿主 API 版本；高于宿主当前版本（v4）时拒绝加载并提示用户升级输入法 |
| `author` | — | 作者名 |
| `description` | — | 一句话描述 |
| `icon_text` | — | 图标字符（emoji 或单个汉字），显示在技能网格；缺省显示 ⚙ |
| `entry` | ✅ | 入口文件的包内相对路径，必须以 `.html` 结尾 |
| `panel_mode` | — | `embed`（工具嵌入，默认）或 `card`（信息卡片，点击结果上屏后收起面板）。当前二者均以 WebView 渲染，语义差异体现在交互约定上 |
| `permissions` | — | 权限数组，见 §7.1；**出现未知权限 id 会导致整个技能拒绝加载** |
| `network_domains` | — | 域名白名单（≤10 个）。仅声明了 `network` 权限时允许非空；只写域名（不含协议/路径/通配符），子域需显式列出（精确匹配） |
| `needs_input` | — | `true` 时技能 UI **提升至编码区上方**（紧凑高度约键盘 60%，下方键盘可用），配合 `input.requestFocus` 实现面板内打字（见 §5.1）；默认 false（覆盖键盘区域） |

> manifest 校验失败的技能不会出现在技能列表中，原因输出在 logcat（tag：`SkillManager`）。

## 3. IMESkill Bridge API 参考

宿主在页面任何脚本执行前注入全局对象 `window.IMESkill`。**所有 API 均返回 Promise**（包括无返回值的方法），失败时 reject 一个 `Error`，`error.message` 为具体原因（如权限拒绝）。

```javascript
IMESkill.apiVersion   // number，当前 3（同步属性，非 Promise）
```

### 3.1 sendText(text) —— 文本上屏 ✅

```javascript
await IMESkill.sendText('北京：晴，26℃');
```

- 文本提交到用户当前正在输入的编辑框（走输入法标准上屏通路，计入打字等级积分）；
- 上屏后**技能面板自动关闭**；
- 限制：非空，≤5000 字符。

### 3.2 getContext() —— 宿主环境信息 ✅

```javascript
const ctx = await IMESkill.getContext();
// { packageName: 'com.tencent.mm', inputType: 'text' }
```

- `packageName`：当前前台编辑框所属应用包名；
- `inputType`：`text` / `number` / `phone` / `datetime`；
- 出于隐私考虑**不提供**选中文本、输入内容等敏感信息，且无需声明权限。

### 3.3 getLocale() / haptic() ✅

```javascript
const locale = await IMESkill.getLocale();  // 'zh-CN'（BCP 47），可用于多语言
IMESkill.haptic();                          // 触发一次按键震动反馈
```

### 3.4 ui —— 面板控制 ✅

```javascript
await IMESkill.ui.setTitle('天气 · 北京');  // 设置宿主返回角标文字（≤20 字符，超出截断）
await IMESkill.ui.close();                  // 主动关闭面板

// 仅 needs_input 技能有效：setExpanded(false) 收缩整个输入法界面——键盘、编码区、
// 候选区一并缩回，面板接管其空间（IME 窗口总高不变），适合查询完成后展示长内容；
// setExpanded(true) 完整恢复；input.requestFocus 会自动恢复（打字需要完整界面）
await IMESkill.ui.setExpanded(false);

// 自定义面板高度（API v4，仅 needs_input 提升挂载有效）：
// ratio 为键盘高度的倍数，宿主钳制到 [0.4, 1.2]，默认 0.6（紧凑高度）；
// 收缩态下调用同样生效（接管高度的基数随之更新）；退回技能列表时自动复位
await IMESkill.ui.setPanelHeight(1.0);  // 面板拉高到与键盘等高
```

> 宿主角标（左上「‹ 技能名」返回胶囊 + 右上「✕」关闭胶囊）由宿主原生绘制并悬浮于页面之上，
> 脚本只能改返回角标的文字、不能遮盖或移除（防钓鱼设计）。

### 3.5 storage —— 轻量 KV 持久化 ✅（需 `storage` 权限）

```javascript
await IMESkill.storage.set('favorite_city', '北京');  // value 按字符串存取
const city = await IMESkill.storage.get('favorite_city');  // 无此 key 时 resolve null
await IMESkill.storage.remove('favorite_city');
```

- 每个技能独立存储空间（按 id 隔离），互相不可见；
- 总量限额 **1MB**（序列化后），超限 reject `存储超限（上限 1MB）`；
- 复杂对象请自行 `JSON.stringify` / `JSON.parse`；
- WebView 的 `localStorage` 已被禁用，持久化只能走本 API。

### 3.6 fetch(url, options) —— 网络代理 ✅（API v2，需 `network` 权限）

```javascript
// url 必须命中 manifest.network_domains 白名单（精确匹配）且为 HTTPS
const resp = await IMESkill.fetch('https://wttr.in/Beijing?format=3');
// resp = { status: 200, body: 'Beijing: ⛅️ +11°C' }
const data = JSON.parse(resp.body);  // JSON 接口自行 parse

// POST 示例
await IMESkill.fetch('https://api.example.com/v1', {
  method: 'POST', body: JSON.stringify({ q: 'x' }), contentType: 'application/json'
});
```

安全限制（宿主侧强制，超限 reject）：

- 强制 HTTPS；域名仅限 `network_domains` 白名单（**禁跟随重定向**，防白名单逃逸，3xx 会原样返回 status）；
- 超时 10s；响应 ≤1MB；频控 ≤30 次/分钟；并发 ≤2；
- 面板关闭时未完成的请求直接取消。

### 3.7 clipboard —— 剪贴板 ✅（API v2，需对应权限）

```javascript
const text = await IMESkill.clipboard.read();   // 需 clipboard_read；无内容 resolve null
await IMESkill.clipboard.write('复制的内容');     // 需 clipboard_write
```

> 剪贴板权限在安装时向用户明示确认；Android 12+ 系统会在读取剪贴板时弹出系统级提示。

### 3.8 input —— 面板内文本输入路由 ✅（API v2，需 manifest `needs_input: true`）

```javascript
// 把键盘上屏文本（含中文候选）改道注入面板内指定 id 的 input/textarea
await IMESkill.input.requestFocus('search-box');
// …用户用下方键盘正常打字（拼音/候选/退格全可用），文本落入 #search-box
await IMESkill.input.releaseFocus();  // 恢复直达宿主应用编辑框
```

行为细节见 §5.1；面板关闭/返回列表时路由自动复位，无需手动 releaseFocus 兜底。

### 3.9 image —— 图片输出 ✅（API v3，需 `image` 权限）

```javascript
// base64 仅支持 PNG（可带 data URL 前缀，如 canvas.toDataURL('image/png') 的返回值）
const url = canvas.toDataURL('image/png');

// 发送到当前输入框（Commit Content 富媒体提交，如微信聊天框）
await IMESkill.image.send(url);

// 保存到系统相册 Pictures/字由输入法/（Android 10+）
await IMESkill.image.saveToGallery(url);
```

行为与限制：

- **仅 PNG**：宿主校验文件头魔数，非 PNG 数据 reject `仅支持 PNG 图片`；
- **send** 要求接收方编辑框声明接受 image 类型（`EditorInfo.contentMimeTypes`），
  不支持时 reject `当前输入框不支持接收图片`，脚本应降级提示改用存相册；
  图片交给输入框后是否自动发送由接收方（如微信）决定，输入法无法绕过其确认逻辑；
- **saveToGallery** 仅 Android 10+（MediaStore 免存储权限），低版本 reject；
- Bridge 单消息 512KB 上限同样约束 base64 体积，超大图请先降分辨率重绘
  （超限消息会被宿主静默丢弃，Promise 不会 resolve）。

完整范例见内置流程图技能（`assets/skills/flowchart/`）：Canvas 自绘导出 PNG →
逐档降 scale 控体积 → send 失败时引导存相册。

## 4. 开发流程

### 4.1 本地编写与浏览器预调

技能就是标准 HTML + JS，可先在电脑浏览器里开发。在页面头部加一段 **mock 垫片** 模拟宿主（发布前删除即可，真机上宿主注入的 IMESkill 优先且垫片幂等）：

```html
<script>
  // 仅本地浏览器调试用：真机上宿主注入的 IMESkill 已存在，此段不生效
  if (!window.IMESkill) {
    window.IMESkill = {
      apiVersion: 1,
      sendText: t => (console.log('[sendText]', t), Promise.resolve()),
      getContext: () => Promise.resolve({ packageName: 'debug', inputType: 'text' }),
      getLocale: () => Promise.resolve(navigator.language),
      haptic: () => Promise.resolve(),
      ui: { setTitle: t => Promise.resolve(), close: () => Promise.resolve() },
      storage: {
        get: k => Promise.resolve(localStorage.getItem('sk_' + k)),
        set: (k, v) => Promise.resolve(localStorage.setItem('sk_' + k, v)),
        remove: k => Promise.resolve(localStorage.removeItem('sk_' + k))
      },
      clipboard: {
        read: () => navigator.clipboard.readText(),
        write: t => navigator.clipboard.writeText(t)
      },
      input: {
        requestFocus: id => Promise.resolve(),
        releaseFocus: () => Promise.resolve()
      },
      image: {
        send: b64 => (console.log('[image.send]', b64.length), Promise.resolve()),
        saveToGallery: b64 => (console.log('[image.saveToGallery]', b64.length), Promise.resolve())
      },
      fetch: (url) => fetch(url).then(r => r.text().then(body => ({ status: r.status, body: body })))
    };
  }
</script>
```

### 4.2 面板尺寸适配

技能面板的位置随阶段切换：**技能列表与普通技能覆盖键盘区域**（候选/编码区保持在上方，
面板高度 = 键盘高度）；**needs_input 技能提升至编码区上方**（高度约键盘 60%）。
内容区占满面板全高，宽度为屏宽；宿主在面板**左上角**（「‹ 技能名」返回角标）与
**右上角**（「✕」关闭角标）各悬浮一个高约 32px 的半透明胶囊，页面顶部两角为
**角标安全区**（左侧预留约 90px、右侧约 40px），避免在此放置关键交互元素。最佳实践：

- 用 `flex` / `grid` 纵向自适应布局，不要写死高度；
- 顶部首行元素为角标让位（如 `margin: 0 40px 0 90px`），或整体下移约 34px；
  纯展示性内容可从半透明角标下方穿过，不影响阅读；
- 根字号 14~17px，按钮足够大（≥40px 触摸目标）；
- 内容超出时给容器 `overflow-y: auto`；
- 背景用 `transparent` 或半透明灰（`rgba(127,127,127,.12)`），自动融入用户的键盘主题。

### 4.3 图形化导入（推荐）

设置页 → 「技能」→ 「技能插件」：

- **导入 .skill 文件**：把技能目录打包为 zip 并改后缀为 `.skill`（注意：manifest.json 必须在 zip 根目录，不要多套一层文件夹），经文件选择器导入；
- **从 URL 导入**：输入 HTTPS 直链下载安装；
- 安装前弹出**权限确认**：展示技能信息、权限清单、可访问域名，确认后才落盘；
- 同 id 技能仅允许**升级**（新版本号必须更高，防降级替换）；内置技能 id 不可覆盖；
- 已安装技能点击可查看详情与**卸载**（同时清除其 storage 数据）。

> 当前不提供「停用/启用」开关：安装即可用、卸载即移除（启用态管理列入后续规划）。
> 内置技能随安装包分发，不可卸载。

打包命令示例（在技能目录内执行，保证 manifest.json 在包根）：

```bash
cd com.user.myskill && zip -r ../myskill.skill . -x '.*'
```

### 4.4 开发者侧载（adb，免打包快速迭代）

## 5. 在输入法中使用技能

1. **唤出**：任意输入框拉起键盘 → 点底部「技」键（QWERTY 第 4 行 / 九宫格底栏）→ 技能列表覆盖键盘区域（候选/编码区保持在上方）；
2. **进入技能**：点技能图标 → 加载该技能页面（左上角悬浮「‹ 技能名」返回角标）；普通技能维持在键盘区域，needs_input 技能提升至编码区上方、键盘露出供打字；
3. **返回 / 关闭**：左上角「‹ 技能名」角标回到技能列表；右上角「✕」角标或再点一次「技」关闭面板恢复键盘；`sendText` 上屏后面板自动关闭；
4. 面板打开时会自动清空未完成的拼音编码；键盘收起（切换应用等）时面板强制关闭并释放资源。

### 5.1 面板内的文本输入：必须走 needs_input + input 路由

技能面板运行在输入法自己的窗口里，系统输入焦点始终在**宿主应用的编辑框**上——直接点面板里的 `<input>` 永远唤不起键盘（输入法不能给自己打字）。宿主提供的解法是**输入路由**：

1. manifest 声明 `"needs_input": true` → 选中该技能后面板**提升至编码区上方**（紧凑高度约键盘 60%），键盘/候选/编码区在下方完整可用；
2. 脚本在用户点击自定义输入框时调用 `IMESkill.input.requestFocus(elementId)`；
3. 此后键盘的上屏文本（含中文拼音候选、退格）全部注入该元素，Rime 编码/候选体验与正常打字完全一致；
4. `IMESkill.input.releaseFocus()` 或退出技能时自动恢复直达宿主编辑框。

注意：注入目标必须是 `input` / `textarea`（垫片按 value + 光标位置插入并派发 `input` 事件）；未声明 `needs_input` 的技能调用 `requestFocus` 会被拒绝。无输入需求的技能仍推荐用按钮/预设选项交互（更简单，面板也更大）。

**配套的阶段切换惯例（输入 → 结果）**：查询完成后调 `IMESkill.ui.setExpanded(false)`，
整个输入法界面收缩（键盘/编码区/候选区一并缩回）、面板接管全部空间展示长内容
（窗口总高不变）；用户再次点输入框 `requestFocus` 时宿主自动 `setExpanded(true)`
恢复完整界面。完整范例见 `skills-dev/com.user.constellation/`。

### 5.2 布局与交互机制详解（原理篇）

#### 三种布局形态

技能面板在输入法视图中的位置随阶段自动切换，脚本无需（也无法）直接控制挂载位置：

```
形态 A：技能列表 / 普通技能        形态 B：needs_input 技能         形态 C：setExpanded(false)
（覆盖键盘区）                    （提升至编码区上方）              （输入法界面收缩）
┌──────────────┐              ┌──────────────┐            ┌──────────────┐
│ 编码区         │              │ 技能面板 0.6kb │            │              │
├──────────────┤              ├──────────────┤            │   技能面板     │
│ 候选词         │              │ 编码区         │            │ （接管全部    │
├──────────────┤              ├──────────────┤            │   空间）       │
│ 技能面板       │              │ 候选词         │            │              │
│（盖住键盘区） │              ├──────────────┤            │              │
│              │              │ 键盘（可用）  │            │              │
└──────────────┘              └──────────────┘            └──────────────┘
```

- A↔B 由宿主按 manifest `needs_input` 自动切换（进入/退出技能时）；
- B↔C 由脚本经 `ui.setExpanded(bool)` 切换；`input.requestFocus` 自动 C→B；
- 三种形态下 **IME 窗口总高度保持不变**（高度守恒：C 的面板高度 = 0.6kb + 键盘 + 候选区实测高度之和），宿主应用界面不会被反复顶起/塌陷。

#### 输入路由（commitTarget）工作原理

系统输入焦点永远在宿主应用的编辑框上，宿主内部用「上屏目标」两态切换文本落点：

```
commitTarget = null（默认）      → 上屏文本直达宿主应用编辑框（计打字等级分）
commitTarget = 技能面板目标    → 上屏文本经 JS 注入面板输入框（不计分）

事件链路（面板态）：
键盘按键 → Rime 编码/候选/选词（全链路不变）→ commit 落点判断
  → evaluateJavascript("__imeskillInput.commit(文本)")
  → 垫片按 value+光标位置插入 requestFocus 登记的元素，派发 'input' 事件
退格（Rime 无编码可删时）同路径走 __imeskillInput.backspace()
```

切换时机（脚本视角只需记住前两条，其余均为宿主自动兜底）：

| 时机 | 目标变化 |
|------|---------|
| `input.requestFocus(id)` 成功 | → 面板目标（同时自动恢复完整输入法界面） |
| `input.releaseFocus()` | → 宿主编辑器 |
| `sendText(...)` | 宿主强制先复位再上屏（保证结果直达聊天框） |
| 返回技能列表 / 关闭面板 / 渲染进程崩溃 | → 宿主编辑器（自动） |

安全边界：路由是宿主→面板的**单向注入**，反方向不存在——技能拿不到用户在其他应用里的任何输入内容。

```javascript
'use strict';
var expr = '';
var display = document.getElementById('display');

function render() { display.textContent = expr === '' ? '0' : expr; }

// 无 eval 的四则运算求值（沙箱 CSP 禁 eval）：双栈算符优先
function evaluate(input) {
  var tokens = input.match(/(\d+\.?\d*|[+\-*/])/g);
  if (!tokens) return null;
  var values = [], ops = [];
  var prec = { '+': 1, '-': 1, '*': 2, '/': 2 };
  function apply() {
    var op = ops.pop(), b = values.pop(), a = values.pop();
    if (a === undefined || b === undefined) throw new Error('bad');
    if (op === '+') values.push(a + b);
    else if (op === '-') values.push(a - b);
    else if (op === '*') values.push(a * b);
    else { if (b === 0) throw new Error('div0'); values.push(a / b); }
  }
  var expectNum = true;
  for (var i = 0; i < tokens.length; i++) {
    var t = tokens[i];
    if (prec[t]) {
      if (expectNum && t === '-') { tokens[i + 1] = '-' + tokens[i + 1]; continue; }
      if (expectNum) throw new Error('bad');
      while (ops.length && prec[ops[ops.length - 1]] >= prec[t]) apply();
      ops.push(t);
      expectNum = true;
    } else {
      values.push(parseFloat(t));
      expectNum = false;
    }
  }
  if (expectNum) throw new Error('bad');
  while (ops.length) apply();
  var result = values.pop();
  if (!isFinite(result)) throw new Error('overflow');
  return parseFloat(result.toFixed(10)).toString();
}

function calc() {
  try {
    var result = evaluate(expr);
    if (result !== null) { expr = result; render(); }
  } catch (e) { display.textContent = '错误'; expr = ''; }
}

document.querySelector('.grid').addEventListener('click', function (e) {
  var k = e.target.getAttribute('data-k');
  if (!k) return;
  IMESkill.haptic();
  if (k === 'C') { expr = ''; render(); }
  else if (k === 'B') { expr = expr.slice(0, -1); render(); }
  else if (k === '=') { calc(); }
  else if (k === 'S') { calc(); if (expr !== '') IMESkill.sendText(expr); }
  else { expr += k; render(); }
});
render();
```

```javascript
'use strict';
// 无输入需求的技能用预设城市按钮交互（更简单；自由输入见 §5.1 needs_input）
var CITIES = ['北京', '上海', '广州', '深圳', '杭州', '成都', '武汉', '西安'];
var CITY_CODE = { '北京': 'Beijing', '上海': 'Shanghai', '广州': 'Guangzhou',
                  '深圳': 'Shenzhen', '杭州': 'Hangzhou', '成都': 'Chengdu',
                  '武汉': 'Wuhan', '西安': 'Xian' };
var resultEl = document.getElementById('result');
var lastText = null;

function renderCities(active) {
  var box = document.getElementById('cities');
  box.innerHTML = '';
  CITIES.forEach(function (city) {
    var btn = document.createElement('button');
    btn.textContent = city;
    if (city === active) btn.className = 'on';
    btn.addEventListener('click', function () {
      IMESkill.haptic();
      IMESkill.storage.set('last_city', city);  // 记住常用城市
      renderCities(city);
      query(city);
    });
    box.appendChild(btn);
  });
}

async function query(city) {
  resultEl.textContent = '查询中…';
  lastText = null;
  try {
    // wttr.in format=3：单行文本 "Beijing: ⛅️ +11°C"；必须走宿主代理（页面自身无法出网）
    var resp = await IMESkill.fetch(
      'https://wttr.in/' + CITY_CODE[city] + '?format=3&m');
    if (resp.status !== 200) throw new Error('HTTP ' + resp.status);
    lastText = resp.body.trim().replace(CITY_CODE[city], city);
    resultEl.innerHTML = '';
    var line = document.createElement('div');
    line.textContent = lastText;                 // 用 textContent，勿拼 HTML（防注入）
    var hint = document.createElement('div');
    hint.className = 'hint';
    hint.textContent = '点击发送';
    resultEl.appendChild(line);
    resultEl.appendChild(hint);
  } catch (e) {
    // 白名单/频控/网络失败统一在此降级（error.message 为宿主给出的具体原因）
    resultEl.textContent = '查询失败：' + e.message;
  }
}

// 点击结果卡片 → 上屏并自动收起面板（card 模式惯例）
resultEl.addEventListener('click', function () {
  if (lastText) IMESkill.sendText(lastText);
});

// 恢复上次选择的城市
IMESkill.storage.get('last_city').then(function (saved) {
  var city = saved && CITIES.indexOf(saved) >= 0 ? saved : null;
  renderCities(city);
  if (city) query(city);
}).catch(function () { renderCities(null); });
```

## 7. 安全机制与隐私

### 7.1 权限一览

| 权限 id | 授予的能力 | 限制 | 状态 |
|---------|-----------|------|------|
| （无需声明） | `sendText` / `getContext` / `getLocale` / `haptic` / `ui.*` / `input.*` | sendText ≤5000 字符；getContext 仅包名+输入框类型；input 另需 manifest `needs_input` | ✅ |
| `storage` | `storage.get/set/remove` | 每技能隔离，总量 1MB | ✅ |
| `network` | `IMESkill.fetch` 宿主代理请求 | 强制 HTTPS、仅 `network_domains` 白名单域（禁重定向逃逸）、超时 10s、响应 ≤1MB、≤30 次/分钟、并发 ≤2 | ✅ |
| `clipboard_read` | 读剪贴板 | 安装时明示确认；Android 12+ 系统另有读取提示 | ✅ |
| `clipboard_write` | 写剪贴板 | — | ✅ |
| `image` | `IMESkill.image.send/saveToGallery` 图片输出 | 仅 PNG（文件头校验）；send 需编辑框接受 image 类型；saveToGallery 需 Android 10+ | ✅ |

未声明权限而调用对应 API 会 reject：`权限拒绝：manifest 未声明 xxx`。

### 7.2 沙箱机制（开发者需要知道的行为边界）

1. **网络全量拦截**：宿主拦截 WebView 的所有资源请求，只放行映射到技能包内的相对路径。`<img>`、`<script>`、`<link>`、CSS `url()` 指向外部 URL 一律返回空响应——**外链 CDN 不可用**，所有依赖请打进技能包。
2. **CSP**：宿主为 HTML 响应注入 `default-src 'self'; script-src 'self' 'unsafe-inline'; connect-src 'none'` 等策略。允许内联脚本；**禁用 `eval` / `new Function`**；页面自身的 `fetch`/`XHR`/`WebSocket` 全部被禁（连接只能走 `IMESkill.fetch`）。
3. **文件系统隔离**：`file://`、`content://` 访问全关；技能只能读到自己包内的文件。
4. **DOM 存储禁用**：`localStorage`/`sessionStorage` 不可用，持久化走 `IMESkill.storage`（可控限额 + 按技能隔离）。
5. **页面跳转封锁**：`location.href` 跳转到外部 URL 会被吞掉，技能只能停留在自身页面体系内。
6. **崩溃隔离**：技能页面渲染进程崩溃时，宿主销毁面板返回技能列表，输入法本体不受影响；Bridge 每次调用均有异常兜底。
7. **反钓鱼**：宿主角标（左上「‹ 技能名」+ 右上「✕」）由宿主原生绘制并悬浮于页面之上（z 序高于 WebView），脚本不可遮盖；技能面板只能出现在键盘区域，无法伪装全屏界面。
8. **通信限制**：Bridge 单条消息 ≤512KB；面板关闭后残留的异步调用被静默丢弃。

### 7.3 用户隐私保护

- 技能**无法读取用户在其他应用的输入内容、编码串、候选词**——Bridge 没有这类 API；input 路由仅把文本注入技能自己的页面，且注入路径不经过脚本可拦截的中间环节之外的任何记录；
- `getContext` 只暴露前台包名与输入框类型，不含选中文本（`selectedText` 设计上已移除）；
- storage 数据仅存在输入法私有目录（`files/skill_data/<id>.json`），卸载技能时一并清理；
- fetch 由宿主代理执行，域名白名单在安装时明示给用户确认，技能无法访问白名单之外的任何地址（含重定向目标）。

### 7.4 安装校验规则与 Bridge 错误速查

**`.skill` 包校验流水线**（导入时逐项执行，任一项失败即拒绝安装并提示原因）：

| # | 校验项 | 规则 |
|---|--------|------|
| 1 | 包体大小 | ≤5MB（边读边卡，超限立即中止） |
| 2 | 条目数 | ≤200 |
| 3 | Zip Slip 路径 | 每个条目必须是安全相对路径：禁 `../`、绝对路径、反斜杠、盘符冒号、NUL、空路径段，单段路径 ≤255 字符；解压时 canonicalPath 二次校验 |
| 4 | manifest 存在且合法 | 见下表；`entry` 文件必须真实存在于包内 |
| 5 | id 冲突 | 与内置技能冲突 → 拒绝；与已安装同 id → 仅允许版本严格更高的升级（防降级替换） |
| 6 | 用户确认 | 展示名称/版本/权限/域名白名单/是否需要面板输入，确认后才落盘（staging 目录原子替换） |

**manifest 字段校验规则**（任一项失败技能不会出现在列表，原因见 logcat `SkillManager`）：

| 字段 | 规则 |
|------|------|
| `manifest_version` | 必须为 1 |
| `id` | `^[a-z][a-z0-9_]*(\.[a-z][a-z0-9_]*)+$`，≥两段、全小写、字母开头，≤100 字符 |
| `name` | 非空且 ≤30 字符 |
| `version` | `^\d+(\.\d+)*$`（纯数字点分，不支持 -beta 等后缀） |
| `min_host_api` | ≥1 且 ≤宿主当前版本（v4），超出提示升级输入法 |
| `entry` | 安全相对路径且以 `.html` 结尾 |
| `panel_mode` | `embed` / `card` |
| `permissions` | 仅限 `network` / `clipboard_read` / `clipboard_write` / `storage` / `image`，**未知 id 整包拒绝** |
| `network_domains` | ≤10 个；纯域名（无协议/路径/通配符）；非空时必须声明 `network` 权限 |

**Bridge reject 错误消息速查**（`error.message`，可用于脚本内分支降级）：

| 消息 | 触发条件 |
|------|---------|
| `权限拒绝：manifest 未声明 xxx` | 调用了未声明权限的 API |
| `域名不在白名单: xxx` / `仅允许 HTTPS 请求` | fetch 目标越界 |
| `请求过于频繁（上限 30 次/分钟）` / `并发请求超限（上限 2）` | fetch 频控 |
| `响应超限（上限 1MB）` / `网络请求失败: xxx` | fetch 响应/网络层错误 |
| `存储超限（上限 1MB）` | storage.set 总量越界 |
| `文本超长（上限 5000 字符）` / `text 不能为空` | sendText 参数越界 |
| `manifest 未声明 needs_input，无法使用面板输入` | 未声明却调 input.requestFocus |
| `当前输入框不支持接收图片` / `仅支持 PNG 图片` / `图片数据无效` | image.send 前置检查 / 数据校验失败 |
| `保存到相册需要 Android 10 及以上系统` / `相册写入失败` | image.saveToGallery 系统版本/写入错误 |
| `未知方法: xxx` | 拼写错误或调用了高版本 API（先查 `IMESkill.apiVersion`） |
| `内部错误` | 宿主未预期异常（已兜底转为通用错误，详情见 logcat `SkillBridge`） |

## 8. 常见问题（FAQ）

| 问题 | 原因与解法 |
|------|-----------|
| 技能没出现在列表里 | manifest 校验失败。`adb logcat -s SkillManager` 看具体原因（id 格式 / 版本号 / entry 路径最常见） |
| 页面里的输入框点了没反应 | 面板内打字必须走 §5.1：manifest 声明 `needs_input` + `input.requestFocus`；或改用按钮/选项交互 |
| 图片/JS 加载不出来 | 外链被拦截或路径带 `../`。资源打进包内、使用纯相对路径 |
| `eval is not allowed` | CSP 禁 eval，改为显式解析（参考计算器的双栈求值） |
| `fetch` 报「域名不在白名单」 | manifest `network_domains` 需精确包含请求域名（子域也要显式列出）；重定向到外域会返回 3xx 而非自动跟随 |
| `fetch` 报「请求过于频繁」 | 频控 30 次/分钟、并发 ≤2，加防抖/缓存 |
| 导入 .skill 提示缺少 manifest.json | zip 根目录必须直接是 manifest.json（打包时多套了一层文件夹，见 §4.3 打包命令） |
| 导入提示「版本不高于现有版本」 | 同 id 仅允许升级，递增 manifest.version 后重新打包 |
| `localStorage` 报错/无效 | DOM 存储已禁用，声明 `storage` 权限并使用 `IMESkill.storage` |
| 上屏后面板关了，想连续发送多条 | `sendText` 语义即"上屏并收起"。连续发送场景等后续版本提供 `sendText(text, {keepOpen: true})` 类扩展，当前可引导用户重新打开面板 |
| 修改代码后真机没生效 | 重新导入（需递增版本号）或重新执行 §4.4 侧载覆盖，再重新打开面板 |
